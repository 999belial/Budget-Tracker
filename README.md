# Budget-Tracker

A simple and intuitive web application to track personal expenses, manage subscriptions, and gain financial clarity. Designed as part of my portfolio to demonstrate skills in state management and responsive web development.

## Features

- **Add Transactions:** Log your expenses quickly.
- **Data Persistence:** Uses `localStorage` to keep your data safe between sessions.
- **Responsive Design:** Works on mobile, tablet, and desktop devices.
- **Multilingual Support:** Available in English and German.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript.
- **Deployment:** Hosted on Vercel.
